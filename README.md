# Мультиагентная AI-система для анализа безопасности смарт-контрактов: выявление и симуляция уязвимостей в блокчейнах Ethereum и TON 

## О проекте

Годовой проект магистерской программы **«Искусственный интеллект»**.

Проект посвящён исследованию методов автоматического анализа безопасности смарт-контрактов с использованием методов машинного обучения, нейронных сетей, LLM и мультиагентных AI-систем.

Основная идея проекта заключается в построении системы, способной анализировать исходный код смарт-контракта, определять класс уязвимости и оценивать вероятность принадлежности контракта к соответствующему классу. На следующих этапах планируется перейти от классификации уязвимостей к их автоматической проверке.

## 🔬 Постановка задачи

Уязвимости в смарт-контрактах могут приводить к нарушению логики протокола, обходу механизмов авторизации, некорректному изменению состояния контракта и потере управляемых им активов.

При этом обнаружение потенциально опасного фрагмента кода ещё не означает, что найденная уязвимость действительно может быть эксплуатирована.

В рамках проекта будет выполнено ряд этапов:

1. Формирование и исследование размеченного набора смарт-контрактов.
2. Классификация контрактов по типам уязвимостей с оценкой вероятности принадлежности к каждому классу.
3. Сравнение классических ML, DL и Agent-подходов.
4. Использование LLM для анализа кода и формирования гипотез о уязвимостях.
5. Создание мультиагентной системы для анализа и проверки найденных проблем.
6. Автоматическая генерация сценария эксплуатации потенциальной уязвимости.
7. Выполнение сценария в изолированной blockchain-среде.
8. Подтверждение или отклонение гипотезы об эксплуатируемости уязвимости.
9. Формирование итогового отчёта по безопасности контракта.

# 📊 Метрики

Для оценки качества классификации планируется использовать:

- **Precision** — доля корректных обнаружений среди всех предсказанных уязвимостей
- **Recall** — доля найденных уязвимостей среди всех реально присутствующих
- **F1-score** — баланс между Precision и Recall
- **Macro F1** — качество классификации с равным учётом различных классов
- **Micro F1** — агрегированное качество классификации по всем объектам
- **PR-AUC** — качество ранжирования для классов, особенно при несбалансированных данных
