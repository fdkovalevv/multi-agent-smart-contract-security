# Данные для EDA

Использован Consolidated Ground Truth (CGT): https://github.com/gsalzer/cgt

Зафиксированный коммит: `f8cd72cf7fbbfebc809c454667eee271706a4b2b`.
Контрольные суммы исходных файлов: `data/raw/cgt_manifest.json`.

Две рабочие таблицы:

- `raw/cgt/consolidated.csv`: 20 455 исходных проверок свойств.
- `processed/contracts.csv`: 3 088 выделенных объявлений (3 078 контрактов и 10 библиотек), метки SWC и характеристики кода.

Метка 1 означает отмеченную слабость, 0 — согласованную отрицательную оценку, пустое значение — неизвестную либо конфликтующую оценку. Конфликт исключает только соответствующую пару «контракт — SWC».

`raw/cgt/source/` содержит 3 103 исходника Solidity. `processed/model_inputs/` содержит 3 088 выделенных фрагментов, на которые ссылается таблица контрактов. Справочники внутри `raw/cgt/construction/` входят в исходный снимок CGT; дополнительных рабочих таблиц EDA они не образуют.

Лицензионные сведения CGT и исходных наборов сохранены в `raw/cgt/LICENSE.txt`, `raw/cgt/README.md` и `raw/cgt/construction/README.md`. Solidity-исходники сохраняют лицензии своих источников.

## Запуск

Из корня репозитория, с Python 3.12:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock.txt
```

Откройте `notebooks/checkpoint2_eda.ipynb` в IDE и выберите созданное окружение. Все файлы для ячеек ноутбука включены; повторное скачивание CGT при наличии снимка не требуется. Проверка SHA-256 выполняется перед анализом.
